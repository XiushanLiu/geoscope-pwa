使用说明

  1. 三个页面：底部胶囊切换「地理 / 气候 / 我的」。桌面图标直接落在「地理」页。
  2. 定位与地点：首次打开会请求定位；拒绝或超时会用默认地点。可在「我的 → 默认地点」改，或在「气候」页的搜索框按地名查找。
  3. 地理页：磁偏角由 WMM2025 模型在本机算出，断网也能用；底图可在街道 / 影像 / 暗色三种样式间切换，用「放大 / 缩小」按钮缩放；手机有方向传感器时可点「启用方向传感器」看罗盘。
  4. 气候页：天气、空气、今日与未来，以及「查看月平均」取 1991–2020 气候常态。有旧缓存时照常显示并标注「更新于 …」，不会留空白。
  5. 添加到桌面：在浏览器菜单里选「添加到桌面 / 添加到主屏幕」。OPPO 自带浏览器没有这个菜单，请改用 360 或 Chrome 打开同一个网址。
  6. 备份：数据只存本机。「我的 → 备份导出」生成 JSON，换机后用「备份导入」恢复；也可以导出 CSV 表格。

磁偏角与网格底图离线可用；离线时天气显示的是上一次的缓存值，并标明更新时间。

关于与边界

  • 不商业化：自用工具，无广告、无第三方统计、无账号登录、无后端。
  • 不做端到端加密同步：数据只存本机 localStorage，搬家靠导出 JSON。
  • 预警不采购数据源：本阶段不实现预警推送。

除已声明的数据源（现有七路）之外，本应用不向任何域名发起请求；你的坐标不会被上传到数据源以外的地方。
